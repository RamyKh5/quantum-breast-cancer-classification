# quantum-breast-cancer-classification
## Overview
A hybrid quantum-classical machine learning project
using PennyLane for binary breast cancer classification.

## Dataset
Breast Cancer Wisconsin (Diagnostic)

Source:
https://www.kaggle.com/datasets/uciml/breast-cancer-wisconsin-data

## Architecture
- 4 qubits
- RY angle encoding
- Trainable RY rotations
- CNOT entanglement
- Pauli-Z measurement

## Technologies
- Python
- PennyLane
- NumPy
- Scikit-learn
- Pandas

## Project Status
Quantum circuit design and initial simulation.
Training and evaluation in progress.
